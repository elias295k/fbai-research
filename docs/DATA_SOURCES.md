# Data sources

## Current repository

Phase 0–1 includes no real football data. Tests use fixtures generated by
`fbai.testing.synthetic` with invented:

- division codes;
- club names;
- match dates;
- outcomes;
- pre-match numeric features.

The generator does not copy, sample, or reconstruct rows from
football-data.co.uk or any other provider.

## Future data policy

Future ingestion work must record, for each source:

- publisher and canonical URL;
- acquisition timestamp and command;
- exact source checksum;
- schema and date coverage;
- licence or terms governing use and redistribution;
- whether the artifact may be committed or must remain local.

Raw, canonical, derived, external, CSV, parquet, and database artifacts are
ignored by default.
