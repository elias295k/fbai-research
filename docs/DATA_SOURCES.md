# Data sources

## Current repository

No real football data is committed. Tests and CI use fixtures generated by
`fbai.testing.synthetic` with invented:

- division codes;
- club names;
- match dates;
- outcomes;
- match statistics;
- pre-match numeric features.

The generator does not copy, sample, or reconstruct rows from
football-data.co.uk or any other provider.

## Acquisition code and attribution

`fbai.data.acquire` can download the configured public CSVs from
[football-data.co.uk](https://www.football-data.co.uk/) without credentials.
It validates supported divisions and season codes, applies explicit connect
and read timeouts, and replaces a destination only after a complete temporary
download succeeds.

Downloaded files are local inputs. `data/raw/`, `data/downloads/`,
`data/canonical/`, `data/features/`, and `data/external/` are Git-ignored,
along with CSV, Parquet, DuckDB, and database artifacts.

## Future data policy

Future ingestion work must record, for each source:

- publisher and canonical URL;
- acquisition timestamp and command;
- exact source checksum;
- schema and date coverage;
- licence or terms governing use and redistribution;
- whether the artifact may be committed or must remain local.

Raw, canonical, derived, external, CSV, parquet, and database artifacts are
ignored by default.
